CSS: Cuando las Vacas Vuelan (Literalmente)

Si te dijeron que tu proyecto funcionaria cuando las vacas volaran, solo necesitabas un poco de CSS absoluto. #CSS #WebDev #Programacion #FrontendTips

Hay momentos en el desarrollo web donde las metaforas se vuelven realidad. Usar un posicionamiento absoluto con valores negativos es como darle alas a cualquier elemento del DOM, incluso a aquellos que deberian estar pastando tranquilamente en el footer.
